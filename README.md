# Quiz Uploader Bot

A ready-to-deploy Pyrogram bot that uploads Telegram quiz polls to a channel.

## Features
- `/start`
- `/help`
- `/uploadquiz`
- `/setdelay`
- `/setchannel`
- `/stop`
- TXT and JSON quiz file support
- Telegram Quiz Poll upload
- Render-ready Docker deployment
